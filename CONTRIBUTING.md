# How We Learn and Contribute

Welcome! This repository is a shared classroom. You do not need to be an expert to participate.

## Weekly rhythm

### Sunday — class
The instructor explains the week's topic, demonstrates code, answers questions, and walks through the assignment.

### During the week — practice
1. Read the lesson notes and run the examples.
2. Attempt the exercises yourself.
3. Complete the assignment in your own branch or fork.
4. Test your work and write a short explanation of what you learned.
5. Submit using the process announced for your cohort.

### Before the next class
Bring questions and errors you could not resolve. We will review common issues together.

## How to ask for help

Include:
- The lesson or assignment name.
- What you were trying to do.
- What you expected to happen.
- What actually happened.
- The smallest relevant code snippet and complete error message.

Remove passwords, API keys, personal data, and other secrets before sharing logs or code.

## GitHub workflow

The instructor will announce the required submission method. For personal practice, a typical workflow is:

1. Fork the repository or create your own branch.
2. Make changes in the relevant exercise or assignment.
3. Run the tests or examples.
4. Commit with a clear message.
5. Open a pull request if requested by the instructor.

Example commit messages:
- `Add Python function exercises`
- `Complete week 2 assignment`
- `Fix API client error handling`

Do not push directly to the main branch unless the instructor explicitly asks you to.

## Code of conduct

- Be respectful and constructive.
- It is okay to ask beginner questions.
- Do not ridicule mistakes.
- Do not submit another learner's work as your own.
- Use AI tools responsibly: understand, test, and be able to explain code you submit.
- Never commit `.env` files, tokens, passwords, private keys, or confidential data.

## What belongs in this repository?

Keep course notes, examples, exercises, assignment instructions, starter code, and project code here. Use the community channel for general discussion and announcements. Do not upload large datasets, private customer data, or copyrighted material without permission.
