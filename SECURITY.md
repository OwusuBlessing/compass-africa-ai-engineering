# Security and Secrets

- Never commit API keys, passwords, access tokens, private keys, or real `.env` files.
- Use `.env.example` to document variable names without real values.
- Use fake or public sample data for exercises.
- If you accidentally publish a secret, tell the instructor immediately and revoke/rotate it. Deleting it in a later commit may not remove it from Git history.
- Never upload employer data, customer records, or other confidential information.
