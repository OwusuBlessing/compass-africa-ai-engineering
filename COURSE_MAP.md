# Course Map

This is the full planned learning path. Lessons are published progressively, after preparation and testing.

| Module | Focus | Module project | Status |
|---|---|---|---|
| 00 | AI Engineering Foundations | Environment and repository setup | Planned |
| 01 | Python for AI Engineers | Python API client communicating with an AI API | Planned |
| 02 | Backend Engineering | FastAPI backend with PostgreSQL and Redis | Planned |
| 03 | LLM Fundamentals | Build an AI-powered API | Planned |
| 04 | LLM Application Engineering | AI-powered document-processing API | Planned |
| 05 | RAG | Chat with your documents | Planned |
| 06 | AI Agents | Research agent that produces structured reports | Planned |
| 07 | Agent Orchestration | Multi-agent research system | Planned |
| 08 | MCP | MCP-powered agent with external tools | Planned |
| 09 | Production AI Engineering | Harden, evaluate, and observe an AI application | Planned |
| 10 | Docker & Deployment | Containerized and deployed AI service | Planned |
| 11 | AI System Design | Design an AI platform from requirements | Planned |
| 12 | Final Capstone | Production-style AI platform | Planned |

## Suggested sequencing

1. Foundations and basic tooling
2. Python fundamentals
3. Backend fundamentals
4. LLM fundamentals
5. LLM application engineering
6. RAG
7. Agents
8. Agent orchestration
9. MCP
10. Production AI engineering
11. Docker and deployment
12. AI system design and capstone

The instructor may interleave a small amount of Git, testing, security, or deployment earlier when it helps learners build good habits. Avoid introducing multiple new frameworks at once.

## Module completion criteria

A module can be marked completed when learners have:
- Attended or reviewed the lesson materials.
- Attempted the core exercises.
- Submitted the module assignment or project.
- Received or completed a review of their work.
