# Assignment Submissions

Follow the submission method announced in `CURRENT_WEEK.md`.

For each assignment, learners should provide:
- Name or cohort identifier, according to the instructor's privacy guidance.
- Assignment/week.
- Repository or pull request link, if applicable.
- How to run the solution.
- Tests performed.
- A short explanation of what was learned and what remains difficult.

Do not upload passwords, API keys, `.env` files, private customer data, or other confidential information. Do not create public submissions containing personal information without consent.
