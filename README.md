# Compass Africa — AI Engineering

**From Python and backend engineering to production AI systems.**

Welcome to the Compass Africa AI Engineering learning repository. This is the shared workspace for weekly lessons, examples, exercises, assignments, and projects.

## Start here

1. Read [`CONTRIBUTING.md`](CONTRIBUTING.md) for the weekly learning and GitHub workflow.
2. Check [`COURSE_MAP.md`](COURSE_MAP.md) to see the full course sequence.
3. Open [`CURRENT_WEEK.md`](CURRENT_WEEK.md) for this week's class, lesson, and assignment.
4. Follow the module instructions in order. If you're a beginner, don't skip the foundations.
5. Ask questions in the community when you get stuck. Share what you tried and the error you received—never post API keys or passwords.

## How the course works

- **Sunday:** 2-hour instructor-led class, live coding, guided practice, and assignment walkthrough.
- **During the week:** complete the assignment, practise, ask questions, and submit your work.
- **Next Sunday:** review common challenges, discuss solutions, and move to the next topic.

Materials are added as the cohort progresses. A folder existing does not mean its lessons are already available.

## Course principles

- Learn by building, not just reading.
- Keep weekly tasks small enough to finish.
- Explain code and decisions, not just copy solutions.
- Ask for help early and respectfully.
- Never commit secrets, credentials, private data, or `.env` files.
- Prefer working, tested code over unnecessary complexity.

## Status key

- `Planned` — on the roadmap, not yet prepared.
- `In progress` — currently being taught or developed.
- `Available` — materials are ready for learners.
- `Completed` — cohort has worked through the material.
