## How to practice
1. Read the matching lesson note under `lessons/`.
2. Attempt the exercise without looking at the stretch task first.
3. Compare your terminal output to **Expected output**.
4. Try the stretch only after the main tasks work.
5. Ask for help with the lesson name, what you expected, what happened, and the error (secrets removed).
